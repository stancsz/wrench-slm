## Diagnosis and applied changes

The first design's arrow was a generic UI symbol rather than an identity.
The above-the-fold file-read diagram explained implementation before visitors
understood the mission. Dense internal evidence vocabulary competed with the
story, and the typography resembled an engineering report.

The revised direction is a warm, approachable model-project identity:

- Original Open W vector mark made from two linked angular forms.
- Primary, monochrome, and avatar variants, with small-size examples.
- Lowercase Manrope wordmark, Manrope headings, DM Sans body text, and
  limited IBM Plex Mono labels.
- Paper, ink, and persimmon palette. Body links use a darker red than the
  decorative mark to improve contrast.
- Centered mission-led hero, two real actions, and original vector hardware
  illustration. Hardware art is explicitly labeled as a vision.
- Working example, current product explanation, and evidence below the hero.
- Separate mission/roadmap, integration, evidence, and brand-asset pages.

The mark is a project design proposal, not a claim of trademark clearance.
The graphical W is an asset independent of the font-based wordmark.

## Verification scope

The static checker validates the exact publishing inventory, local links,
fragments, headings, and example receipt. SVGs are parsed as XML. Browser
review covers desktop/mobile layout, image loading, saved example switching,
copy controls, and documentation navigation. Visual review does not imply
the owner has accepted this design.
