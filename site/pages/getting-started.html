01 / Getting started

Your first local result.

Read one setting, reject an out-of-bounds path, and decline a shell command. See the actual verifier at work with no model download or API key.

Access today: Wrench’s source repository is private. The commands below are for people who already have access. There is no public install release yet. Anyone can explore the saved example and its results.

What you need

  • Python 3.11 or later and Git.
  • An authorized source checkout of Wrench.
  • No GPU, model weights, provider account, or API key for this example.

This shows a narrow Python verifier path. It does not establish hardware compatibility or resource requirements for model inference.

1. Set up an isolated environment

Clone the repository using your existing GitHub access, then install the local Python package. The installation may download Python build tooling; running the example makes no network calls.

git clone https://github.com/stancsz/wrench-slm.git
cd wrench-slm
python -m venv .venv

Download the example script and save it as local_first.py in the checkout’s root directory. The public download contains only this small example, not the private runtime.

Windows PowerShell

.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe local_first.py

macOS or Linux

Use python3 to create the environment if that is your Python command. The example uses portable Python APIs; the documented commands were verified on Windows.

.venv/bin/python -m pip install -e .
.venv/bin/python local_first.py

2. Check the result

The example script creates a temporary settings.txt containing two settings. It passes three proposals to the real verifier, confirms the file is unchanged, and removes its temporary fixture when it exits.

RequestExpected resultMeaning
Read line 1accepted, timeout=30A bounded read succeeded.
Read ../outside.txtpath_outside_allowed_rootThe read cannot leave the allowed directory.
Run a shell commandaction_not_allowlistedThe verifier offers no arbitrary shell action.

The last field should be "fixture_unchanged": true. Compare with the captured result.

3. Understand the call

from wrench_harness import execute_proposal

result = execute_proposal(
    {
        "schema": "wrench.proposal.v1",
        "action": "read_lines",
        "path": "settings.txt",
        "start": 1,
        "end": 1,
    },
    allowed_root="path/to/your/fixture",
)

You supply the allowed directory. The verifier checks the proposal and returns either an accepted observation or an abstention with a reason. This direct example does not start a server, choose a model, or contact a fallback provider.

If something goes wrong

  • Repository not found: confirm that your GitHub account has access. This is not an anonymous public download.
  • No module named wrench_harness: install with the same virtual-environment Python you use to run the example.
  • allowed_root_invalid: the directory passed to the API must already exist.
  • missing_path: the requested file must exist inside that directory.
