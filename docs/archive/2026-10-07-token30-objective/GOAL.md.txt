# Wrench direction: selective local routing with frontier fallback

Updated: 2026-10-03 (America/Edmonton)
Owner: human product owner; repository agent maintains the evidence

Wrench is a local context and routing layer for coding agents. Its goal is to
intercept work a small local model can handle reliably, and route uncertain or
hard work to the user's stronger frontier model. Wrench does not aim to replace
frontier models for every task.

Qwen is the foundation, not the finished Wrench router. A Wrench LoRA adds
task-specific routing behavior that Qwen does not have by default. The LoRA
proposes bounded route choices from evaluated task families. Deterministic
policy enforces allowed routes, and independent verification checks local
results. When evidence or confidence is insufficient, Wrench hands off with
the needed context. The system must demonstrate that its savings survive
fallback, verification, retries, and local operating cost.

The release path prioritizes reproducible proof over model expansion:
1. Ship a useful, deterministic context and routing baseline with complete
   lifecycle receipts.
2. Evaluate one small-model-plus-Wrench-LoRA route on frozen, diverse tasks;
   expand only task families that retain quality while reducing total cost.
3. Validate integration, recovery, installation, licensing, data provenance,
   and a reproducible public artifact before calling Wrench release-ready or
   publishing weights/data to Hugging Face.

The v1 pruning and binary-only objectives are superseded. Earlier 95/5 and
95%-savings targets are historical hypotheses, not product-wide routing quotas
or release gates. Current acceptance is quality-gated selective coverage and
measured full-workflow benefit, as defined in the North Star and experiment.

in the gateway goal linked above. It does not mark the deterministic baseline,
local-model task families, product-wide savings, release readiness, or a
Hugging Face publication as accepted. Current metrics and gates are in the
experiment record.

analysis. They do not establish v2 capability. The former corpus goal, paid
