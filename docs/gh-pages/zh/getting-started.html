01 / 先跑起来

先跑个小的，
不用搬出显卡。

读一行配置，拦住一次越界，再拒绝一条 shell 命令。你会看到真正的校验器怎么工作，不用下载模型，也不用掏 API Key。

先说清楚入口：源码仓库已公开，可以按下面的命令从源码体验。目前没有正式安装版，具体开放许可证仍待公布。也可以先看网页示例和实际保存的结果。

需要准备什么？

  • Python 3.11 或更高版本，以及 Git。
  • 从公开仓库克隆的一份 Wrench 源码。
  • 这个例子不需要 GPU、模型权重、模型服务账号或 API Key。

这次只体验 Python 校验器这一小段。它能跑，不代表模型推理也适配了你的硬件。先别急着给旧显卡开香槟。

1. 给它单独留个环境

克隆公开 GitHub 仓库，再安装本地 Python 包。安装时可能会下载 Python 构建工具；运行例子本身不联网。

git clone https://github.com/stancsz/wrench-slm.git
cd wrench-slm
python -m venv .venv

下载示例脚本，以 local_first.py 为名放在仓库根目录。这个下载只有示例，运行时需从上面的源码仓库安装。

Windows PowerShell

.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe local_first.py

macOS / Linux

如果你电脑上的命令叫 python3，创建环境时就用它。示例用的是跨平台 Python 接口；这里的命令实际在 Windows 上验证过，其他平台还没替你打包票。

.venv/bin/python -m pip install -e .
.venv/bin/python local_first.py

2. 看它交了什么作业

脚本会建一个临时 settings.txt，写入两项配置，再把三个操作提案交给真正的校验器。最后检查文件没有被改动，退出时清理自己建的临时目录。

试什么应该看到什么说明什么
读第 1 行accepted，timeout=30范围内的读取成功。
读 ../outside.txtpath_outside_allowed_root不许溜出指定目录。
执行 shell 命令action_not_allowlisted这里没有任意执行 shell 的权限。

最后应该有 "fixture_unchanged": true。意思是测试文件完好无损。可以和这份实际结果对一下。

3. 核心调用其实就这几行

from wrench_harness import execute_proposal

result = execute_proposal(
    {
        "schema": "wrench.proposal.v1",
        "action": "read_lines",
        "path": "settings.txt",
        "start": 1,
        "end": 1,
    },
    allowed_root="path/to/your/fixture",
)

你指定允许访问的目录，校验器检查提案，然后返回读取结果，或者带着原因拒绝。这段调用不会启动服务器、选择模型，也不会去找云端模型接手。

卡住了？先看这几处

  • Repository not found：确认 GitHub 账号有仓库权限，目前不是匿名可下载的项目。
  • No module named wrench_harness：安装和运行要用同一个虚拟环境里的 Python。别让两个 Python 互相装不认识。
  • allowed_root_invalid：传进去的目录得先存在。
  • missing_path：目标文件得在允许的目录里，而且确实存在。
