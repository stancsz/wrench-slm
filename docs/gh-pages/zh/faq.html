05 / 你大概会问

先把这些
实在问题聊明白。

多少钱？要什么显卡？能不能用？这里不绕弯子。

Wrench 免费吗？会开源吗？

会。我们的方向很明确：源码开源，模型权重开放，数据集也开放。Open source. Open weights. Open datasets.

希望你不光能免费用，还能看懂它怎么做、自己改、自己跑，一起把 AI 的成本打下来。开放发布还在准备中，下载入口和具体许可证会随发布一起公布。

文档里的本地例子不调用模型和付费 API；你的电脑耗电、以及自己配置的云端备用调用，仍然可能有成本。

能把我的 ChatGPT 或编程助手月费降下来吗？

不会自动降。包月订阅只要套餐没变，账单就还是那个数。最直接要验证的是：同样的活儿干完，按量计费的调用能不能少花钱。也许还能缓解额度压力，但那也得看实际工作流，不能隔空报喜。

得买新显卡吗？

我们的起点恰恰是显存不到 8 GB 的朋友。下一站是不到 2 GB 的有用流程，也探索旧手机。这些还是目标，不是兼容性承诺。当前不调用模型的 Python 例子无需 GPU。细节在路线图。

现在能把闲置算力借给朋友了吗？

还不能。这是长期想做的事：自愿把闲着的计算能力分享给信得过的人。目前没有实现朋友间共享算力的网络。

它要取代我的编程助手吗？

现在的 Wrench 负责有边界、能验证的开发工具任务。复杂推理、代码修改和范围外的请求仍由更大的工作流负责。它不会自己接个新功能，然后一路写完上线。

和 coder 模型有什么区别？“更能扛事情”是什么意思？

我们为配合大模型、把整条工作流的成本打下来而做。大模型理解需求、解决难题；Wrench 接住范围清楚的读文件、精确搜索和查状态等重复步骤，通过本地规则、独立验证和有边界的执行把结果带回来。

“更能扛事情”是希望本地多分担实际工作，让整条流程少绕路、少返工。它还不是已经在所有场景胜过 coder 的实测结论。Coder 也能配工具和验证，Wrench 得用同样任务的成功率、总成本和耗时证明价值。看具体分工 →

Abstain 是最大的卖点吗？

它是重要的交接机制：超出范围、证据不足或验证不通过，就把控制权交回调用方。真正的卖点应该是该接的做对、该退的退干净，整个任务还省了钱。什么都拒绝，只会多绕路。目前主要靠规则和独立检查做这个判断，学习式自由路由仍关闭。看看怎么判断它有没有用 →

我有 ripgrep 和 Git，为什么还需要它？

这俩本来就很好用。Wrench 想补的是 AI 工作流中的结构化操作提案和校验边界。它必须证明：和直接用强模型、或简单规则加备用模型相比，这层接入真的有价值。多一层东西，就得多交一份有用的答卷。

我的数据都会留在本地吗？

Python 小例子不联网。但如果完整工作流配了云端备用模型，客户端可能会把上下文发送给服务商。试用时先选不敏感的工作区，并检查客户端的数据流。我们不承诺所有用法都完全离线。

会不会偷偷改我的文件？

这套工具只允许读取或生成供审阅的结果。补丁草稿不会被这个 worker 应用。示例脚本会自行创建和清理临时测试文件，方便你看清操作边界。

想帮忙，从哪里开始？

拿一个你经常让编程助手做的小任务就很好：你怎么提问，什么结果算对，时间或 token 花在哪儿。通过你已有的项目联系渠道给维护者一个去掉敏感信息的小例子就行。别把密钥、私有代码或原始服务商日志一起打包。也可以到公开项目仓库查看进展；正式分发版本仍在准备中。
