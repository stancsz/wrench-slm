What the receipts prove.

V21 is a release-ready LoRA adapter for the declared Wrench-Pro contract. The exact package passed the frozen holdout, a fresh context suite, and a clean-environment load using the pinned Qwen base.

The evidence supports the adapter and its bounded local runtime. It does not establish router savings, arbitrary shell reliability, hosted serving, or production traffic quality.

Keep the package immutable while router integration, hardware coverage, and deployment are evaluated as separate work.

Separate work

What remains outside the release.

  • Publish the adapter to its chosen model registry and verify the remote checksums.
  • Measure Flash and Pro on target hardware, including p99 latency and memory.
  • Run router integration and hosted serving gates with live request evidence.
  • Evaluate any merged, quantized, or converted artifact again.
  • Establish production traffic reliability separately from authored evaluation.
Guardrails already encoded

Safety is a routing decision.

  • Only read-only and diagnostic tools may be speculatively pre-executed.
  • Mutations and destructive actions remain behind verification.
  • Protocol generation is constrained by a finite-state grammar.
  • Held-out data remains separated from training and reward calculation.

The operating principle: narrow scope, explicit proof, safe escalation.
