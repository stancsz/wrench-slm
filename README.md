# Wrench

Wrench is being rebuilt as a small local component for narrowly defined,
independently verifiable developer-tool work.

It may propose a bounded action or abstain. A separate verifier and router own
execution, fallback, accounting, circuit breaking, and rollback. The project is
not a general coding agent and has no autonomous-write authority.

The initial investigation is whether a modern sparse coding-model checkpoint can
be structurally reduced and calibrated for this narrow role. No model identity,
architecture, performance claim, or release decision is assumed until it is
verified from the actual licensed checkpoint and measured on the target runtime.
