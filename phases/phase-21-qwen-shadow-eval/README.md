# Phase 21: real Qwen shadow portfolio evaluation

This phase sends five accepted-action proposal shapes from the proposed
portfolio through the real local Qwen runtime, the localhost adapter, and the
independent verifier. The receipt records per-case acceptance, fallback reason,
token usage, and wall time without storing raw prompts or generated text.

The portfolio remains pending human approval. This is shadow observation only,
not calibration, final evaluation, proposal precision, or workflow-success
evidence.
